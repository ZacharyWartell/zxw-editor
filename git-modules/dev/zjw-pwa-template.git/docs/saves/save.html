Instructions

_Div_
  1. Create new directory:     
    | $ mkdir project-foo-bar
  2. Git init:   
    | project-foo-bar $  git init
  3. Add zjw-pwa-template submodule:   
    | project-foo-bar $  git add submodule https://gitlab.com/zachary-wartell-public/zjw-pwa-template.git git-modules/zjw-pwa-template
  4. Run zjwp-init-project.   The script will asked you several questions that will be used to customize the template files.
    | project-foo-bar $  git-modules/zjw-pwa-template/zjwp-init-project
