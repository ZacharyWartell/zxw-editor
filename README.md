# zxw-editor

### Author: Zachary Justin Wartell, Ph.D.
- Git: https://github.com/ZacharyWartell/zxw-editor
- License: [LICENSE.md](LICENSE.md)

Experimental 'in-place' HTML editor.

- Leverages [contentedible](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Global_attributes/contenteditable) and [showSaveFilePicker](https://developer.mozilla.org/en-US/docs/Web/API/Window/showSaveFilePicker) to save changes to local file
- Test with Chrome browser
- Assumes user is comfortable and familiar with using the Chrome Inspector to edit the DOM in addition to editing the contentedible directly using the browsers inherent
  [contentedible](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Global_attributes/contenteditable) editing features.
